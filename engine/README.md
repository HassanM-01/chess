# Native Stockfish

The desktop app looks for `stockfish.exe` (or `stockfish` on macOS/Linux) in this folder. The binary itself is not committed
(it is ~100 MB); get it from the official releases and drop it here:

<https://github.com/official-stockfish/Stockfish/releases> → `stockfish-windows-x86-64-universal.zip` (picks the fastest build for your CPU at start-up)

Rename the executable to `stockfish.exe`, or point the app at any Stockfish with **Settings → Choose a different Stockfish…**.
Stockfish is GPLv3; keep `Copying.txt` next to the binary when you redistribute the app.
